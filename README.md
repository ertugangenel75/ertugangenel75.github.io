ISDBM Digital — Argeplano'nun arsa/parsel yatırım analiz platformu. Tam bir SaaS akışı var: login → dashboard → parsel seçimi → analiz → yatırım kararı → rapor.
Login ekranı — kullanıcı adı/şifre validasyonu, hata mesajı
Dashboard — proje tablosu, skor özeti, hızlı işlemler

Lokasyon girişi (İl / İlçe / Mahalle / Ada / Parsel)
Harita + parsel bilgileri
Analiz sonuçları (6 metrik, döngüsel skor göstergeleri)
Yatırım alternatifleri tablosu (6 seçenek, ISDBM skorları)
Yatırım Kararı ekranı — Data Center Campus, aşamalı geliştirme stratejisi, finansal göstergeler, rapor özeti
